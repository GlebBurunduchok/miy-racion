Мій раціон 4.1 — GitHub Pages

1. Распакуй архив. Открой репозиторий → Add file → Upload files.
2. Перетащи СОДЕРЖИМОЕ папки GitHub_Upload_v4_1: index.html, JS/CSS, assets, vendor и остальные файлы.
3. Дождись окончания загрузки и нажми Commit changes.

index.html должен быть в корне выбранной папки публикации GitHub Pages. Сам ZIP загружать как сайт не нужно.

OCR работает на устройстве. Фотография этикетки не отправляется на сервер. Движок и три языковые модели включены; API-ключи и отдельная регистрация не нужны. При первом запуске сканера модели загружаются с твоего сайта, затем кешируются. Для камеры нужен HTTPS или localhost.

Фотографии 103 базовых продуктов встроены в один JS-файл, чтобы весь комплект помещался в одну загрузку через браузер. Авторы и лицензии доступны в настройках и INGREDIENT_PHOTO_SOURCES.md.

После обновления дождись публикации GitHub Pages и обнови страницу приложения. Если установленная PWA показывает старый интерфейс, полностью закрой её и открой снова. Дневник хранится в этом браузере на том же адресе сайта. Не очищай данные сайта без резервной копии.
