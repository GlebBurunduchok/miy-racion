Мій раціон 4.0 — комплект для GitHub Pages

1. Откройте репозиторий и выберите Add file → Upload files.
2. Перетащите СОДЕРЖИМОЕ этой папки: файлы index.html, sw.js, остальные JS/CSS, assets и vendor.
3. Дождитесь завершения загрузки и нажмите Commit changes.

index.html должен лежать в корне выбранной папки публикации GitHub Pages. Не загружайте ZIP как сайт и не вкладывайте эту папку внутрь старой папки проекта.

Функции дневника, календаря, профиля, базовых продуктов и распознавания сохранены. OCR обрабатывает фото на устройстве, но файлы движка и языка загружаются с CDN, поэтому для распознавания нужен доступ к интернету. Здесь нет больших локальных OCR-моделей. Полная версия для localhost и самостоятельного хранения моделей остаётся в Mii_Ratsion_Source_v4_0.zip.

Существующий дневник не очищается. При открытии сайта по прежнему адресу записи сохраняются в прежнем браузере. Эта папка содержит только файлы сайта, без личных данных.
