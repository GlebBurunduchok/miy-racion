# Мій раціон 2.2

## Новое в 2.2

- На мобильных устройствах все поля ввода, включая дату, граммы, поиск и списки, используют шрифт 16 px. Это устраняет типичный автоматический зум при фокусе на iOS. Ручное увеличение жестом сохранено.
- Перерисованы круги БЖУ: единые карточки с процентом, количеством и ориентиром. Сахара, соль, насыщенные жиры, клетчатка и доступные минералы расположены ниже, в одной группе. Большая диаграмма состава заменена компактным раскрывающимся распределением энергии.
- Сканирование отличает отсутствующий продукт от карточки с неполной этикеткой. Название, бренд, фотография и известные значения сохраняются; пропущенные значения остаются пустыми. Полную этикетку можно внести и сохранить с исходным штрихкодом для повторного использования без сети.
- Добавлен пример карточки «Карпатська Джерельна», код 4820051240233, с фотографией из Open Food Facts. У этого источника нет КБЖУ: для обычной воды без добавок предусмотрено явное подтверждение нулевых КБЖУ. Это действие не заполняет соль, сахар или минералы и не применяется автоматически ко всем водам бренда. Код другой бутылки нужно проверять отдельно.
- Учитываются эквивалентные UPC/EAN/GTIN с ведущим нулём. Полный продукт с этим кодом, сохранённый пользователем, имеет приоритет перед неполной онлайн-карточкой.
- Расширены ссылки на исходные фото популярных продуктов: 64 предварительно обработанные карточки, у 62 есть ссылка на фото. В серверном режиме фотографии видимых карточек подгружаются автоматически, с ограничением числа одновременных запросов. Для Milka и указанной воды фото встроены в самостоятельный HTML. Если у источника нет фото или оно недоступно, отображается значок категории.

## Нутриенты

Неизвестное значение обозначается «—». Частичная сумма за день помечена «≥»; приложение не считает пропуски нулями. Цвет показывает отношение к указанной цели или справочному ориентиру. Дополнительные ориентиры можно изменить в настройках; они сохраняются в резервной копии.

Исходные дополнительные ориентиры: общие сахара 90 г, соль 6 г, насыщенные жиры 20 г — [референсные значения маркировки ЕС для взрослых](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=oj%3AJOC_2018_196_R_0001); клетчатка 25 г — [ориентир EFSA](https://www.efsa.europa.eu/en/press/news/nda100326). Это справочные значения, а не индивидуальное назначение. Общие сахара и свободные сахара различаются.

## Запуск

**Для полного поиска на Windows:** распакуйте архив и дважды нажмите `Start.cmd`. Откроется браузер с приложением. Окно сервера оставьте открытым. Нужен установленный Node.js 18 или новее. Зависимости устанавливать не требуется.

Другой вариант: `node server.mjs`, затем открыть `http://localhost:4173`. Другой порт: `node server.mjs 8080`. Остановить сервер — Ctrl+C.

**Для просмотра без сервера:** откройте `Mii_Ratsion.html`. В одном HTML находятся интерфейс, фотографии, сканер и 8 932 карточки. Прямой поиск Open Food Facts включён, но зависит от ограничений браузера и доступности сервиса. Поиск по всей базе «Таблиці Калорійності» требует запуска через сервер: её источник не разрешает прямые запросы из стороннего HTML. В серверной версии приложение автоматически обращается к обоим каталогам через свой локальный API.

Для телефона нужен размещённый на HTTPS сервер. Одна загрузка HTML на статический хостинг не создаёт серверный API. Манифест и service worker включены; камера требует разрешения браузера и защищённого контекста (HTTPS или localhost).

## Что изменилось

- Удалены имя, аватар пользователя и повторное знакомство через шестерёнку. Шестерёнка открывает обычные настройки.
- Параметры редактируются на месте. История питания, вода, вес, избранное и ручные цели сохраняются.
- Вместо возраста вводится год рождения. Профиль первой версии автоматически преобразуется в новый формат, если открывается тот же адрес приложения.
- Более короткие тексты, компактный дневник, единая строка поиска. Нет отдельной кнопки поиска в Open Food Facts.
- Поиск запускается после короткой паузы ввода. Предыдущий запрос отменяется, устаревшие ответы игнорируются. Повторные запросы кешируются.
- 8 931 записей встроены в приложение: 137 базовых, 1 000 из публичного каталога «Таблиці Калорійності», 7 793 из USDA SR Legacy Milka Oreo и одна неполная карточка воды из Open Food Facts.
- В серверной версии автоматический поиск получает дополнительные результаты из текущих каталогов «Таблиці Калорійності» и Open Food Facts.
- Быстрые веса порций, недавние продукты, избранное, категории и постраничное отображение большого каталога.
- Отмена удаления записи, повтор вчерашнего рациона, ввод собственных продуктов и импорт CSV/TSV/JSON.

Это не полная офлайн-копия миллиона записей стороннего сайта. Названия импортированных продуктов сохраняются на языке источника; интерфейс доступен на украинском, русском и английском. В поиске есть межъязыковые синонимы для распространённых продуктов.

## Сохранение и перенос записей

Данные находятся в браузере под прежним ключом `mii-ratsion.v1`; внутренняя версия схемы теперь 2. При открытии на том же адресе старая история переносится автоматически, а имя удаляется из профиля. Переход от локального HTML к `localhost`, другому порту или другому устройству меняет хранилище: сначала сохраните резервную копию в старой версии, затем восстановите её в новой.

Ручные цели не перезаписываются при сохранении профиля. Отдельная кнопка пересчёта в блоке дневных целей заменяет их расчётными значениями. Экспорт и восстановление первой и второй версий поддерживаются. Повреждённые данные не принимаются как корректная копия.

Профиль, вес и дневник не отправляются источникам продуктов. Во внешние каталоги передаются только запрос поиска или штрихкод. Фото штрихкода обрабатывается на устройстве.

## Импорт продуктов

В разделе «Продукты» нажмите кнопку импорта. Поддерживаются CSV, TSV и JSON, до 10 000 строк в одном файле. Перед импортом показывается число новых записей. Полностью совпадающие названия и КБЖУ повторно не добавляются.

CSV, значения **на 100 г**:

```csv
name,kcal,p,f,c
Мой продукт,120,10,4,11
```

Поддерживаются также украинские и русские заголовки, разделитель `;`, кавычки и десятичная запятая. JSON — массив объектов с `name`, `kcal`, `p`, `f`, `c`. Отсутствующее значение не подменяется нулём. Пустые, отрицательные и выходящие за допустимые пределы значения отклоняются.

## Расчёты

Возраст определяется как текущий год минус год рождения, без месяца и дня. В вычислении основного обмена используется `max(18, возраст)`. Формула Mifflin–St Jeor умножается на коэффициент активности 1.2 / 1.375 / 1.55 / 1.725 / 1.9. Поддержание — 100%, снижение — 85%, набор — 110%; при ИМТ ниже 18,5 автоматический дефицит не применяется. Выбор «использовать свои цели» отключает автоматическую оценку. БЖУ: 25% / 30% / 45% энергии. Это параметры расчётной модели приложения, а не проверенная персональная норма. Вода — самостоятельно настраиваемая цель.
