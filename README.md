# Мій раціон 3.0

## Новое в 3.0

- Полностью обновлён интерфейс: недельная лента дат, компактный обзор калорий и БЖУ, карточки приёмов пищи, сворачиваемые дополнительные нутриенты.
- Порции в граммах, миллилитрах, штуках и упаковках. Размер штуки или упаковки запоминается для продукта. Для пересчёта массы и объёма требуется указанный вес 1 мл; приложение не предполагает, что 1 мл любого продукта равен 1 г.
- Свои рецепты: ингредиенты, вес готового блюда и количество порций. КБЖУ рассчитываются на 100 г и на порцию. Неизвестные дополнительные нутриенты не подставляются нулями.
- Редактирование продуктов, привязка штрихкода и свои фотографии через карандаш в карточке продукта. Уже сохранённые приёмы пищи сохраняют прежние значения.
- Повтор предыдущего приёма пищи с возможностью отмены. Кнопка появляется рядом с приёмом пищи, для которого есть предыдущие записи.
- Статистика за 7 и 30 дней: средние КБЖУ по дням с записями, число заполненных дней, график и изменение веса.
- Ежедневный огонёк: первая запись еды за сегодня зажигает его; дополнительные записи не увеличивают счётчик. На следующий день огонь тёмный, предыдущая длина серии ждёт новую запись. Пропуск полного дня обнуляет серию. Есть анимации зажигания, остывания и угасания и настройка уменьшения движения.

Стрик учитывает местную календарную дату. Вода и создание рецепта отдельно его не зажигают. Новые записи задним числом или заранее не восстанавливают пропущенную серию. Старые записи версии 2.3 учитываются без сброса дневника. При удалении последней подходящей записи за день серия пересчитывается.

Свои фото сжимаются на устройстве, сохраняются один раз и входят в JSON-резервную копию. Поддерживаются JPG, PNG и WebP до 10 МБ на входе; локальная коллекция ограничена 64 фотографиями и общим объёмом 3 млн символов после сжатия. Изображения и дневник не отправляются источникам продуктов.

## Сохранённые возможности версии 2.3

Дневник питания на украинском, русском и английском языках. Данные дневника хранятся в браузере на текущем устройстве.

## Что изменено

- У 966 из 1 000 встроенных карточек «Таблицы калорийности» добавлены ссылки на исходные фотографии. Они доступны и в статической версии на GitHub Pages. Изображения загружаются с сайта источника; без интернета доступность зависит от кеша браузера.
- Верхняя панель учитывает безопасную область экрана iPhone, нижнее меню — область системного индикатора. Добавлены боковые отступы для горизонтальной ориентации. После первого заполнения параметров дневник открывается с начала страницы.
- Новый значок: тарелка, вилка и нож. Есть SVG и PNG для сайта, iPhone и установки приложения.
- Все мобильные поля ввода имеют размер шрифта 16 px. Автоматический зум при фокусе устранён; ручное увеличение жестом сохранено.
- Дополнительные нутриенты и доступные минералы находятся под БЖУ в одном блоке. Значения пересчитываются при изменении порции.
- Код отформатирован, удалены 146 неиспользуемых правил старого интерфейса. Хранение вынесено в отдельный модуль; сборка и офлайн-кеш используют единый список файлов.
- Ошибка записи в хранилище не маскируется сообщением об успешном сохранении. Невалидные данные не перезаписывают сохранённый дневник. При повреждённой старой записи сохраняется её копия перед заменой.

## Запуск

Для просмотра без сервера откройте **Mii_Ratsion.html**. Это один файл с интерфейсом, локальным каталогом и встроенным сканером. Фотографии продуктов с внешних сайтов требуют сети; фото Milka и примера воды встроены в HTML.

Для полноценного локального запуска установите Node.js 18 или новее, распакуйте архив и откройте **Start.cmd**. Другой вариант — выполнить **npm start** и открыть http://localhost:4173. Дополнительные зависимости устанавливать не нужно. Остановка сервера — Ctrl+C.

Для камеры на телефоне нужен сайт на HTTPS и разрешение браузера. Сканирование камерой, по фотографии и ввод кода вручную предусмотрены.

## GitHub Pages

Замените файлы репозитория содержимым архива, включая папки assets и vendor. Главная страница — index.html. Дождитесь публикации, закройте старую вкладку или установленное приложение и откройте сайт снова.

Не очищайте данные сайта ради обновления: в них хранится дневник. Если на рабочем столе iPhone остался старый значок, можно удалить только ярлык и добавить сайт на главный экран заново, сохранив данные Safari.

| Дневник, настройки, цели, резервные копии | Да | Да |

GitHub Pages не запускает server.mjs. Для полного внешнего каталога требуется отдельный сервер с Node.js. При отказе одного источника локальные результаты остаются доступны.

## Данные и расчёты

В каталоге 8 931 полных продуктов и одна неполная карточка воды: 137 базовых, 1 000 из «Таблицы калорийности», 7 793 USDA SR Legacy и Milka Oreo; отдельно — «Карпатська Джерельна», код 4820051240233.

Неполная карточка не означает отсутствующий продукт. Приложение сохраняет его название, фото и штрихкод и предлагает заполнить значения с этикетки. Для обычной воды без добавок доступно явное подтверждение нулевых КБЖУ. Оно не заполняет сахар, соль или минералы и не применяется ко всем вариантам воды бренда. Сохранённый продукт с кодом доступен для повторного поиска без сети.

Все продуктовые значения приводятся на 100 г. Неизвестные дополнительные нутриенты обозначаются «—»; частичная сумма за день — «≥». Пропуски не превращаются в нули. Ориентиры сахара, соли, насыщенных жиров и клетчатки можно изменить в настройках. Исходные значения: 90 г / 6 г / 20 г / 25 г. Это справочные ориентиры для взрослых, а не индивидуальное назначение: [маркировка ЕС](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=oj%3AJOC_2018_196_R_0001), [клетчатка EFSA](https://www.efsa.europa.eu/en/press/news/nda100326).

Возраст определяется по году рождения. В основной формуле используется max(18, возраст). Mifflin–St Jeor с коэффициентами активности 1.2 / 1.375 / 1.55 / 1.725 / 1.9; поддержание 100%, снижение 85%, набор 110%. При ИМТ ниже 18,5 автоматический дефицит не применяется. Можно задать собственные цели. Источник формулы: https://pubmed.ncbi.nlm.nih.gov/2305711/.

## Резервные копии и импорт

Экспорт и восстановление дневника доступны в настройках. Ключ хранения mii-ratsion.v1 сохранён, версия схемы — 2. Обновление на том же адресе сохраняет дневник. Для перехода между разными адресами и устройствами сначала экспортируйте резервную копию.

Список собственных продуктов можно импортировать из CSV, TSV или JSON. Обязательны название и четыре числовых значения на 100 г: name, kcal, p, f, c. Поддерживаются десятичные запятые, кавычки и разделитель «;». Допускается до 10 000 строк в одном файле. Пустые значения КБЖУ отклоняются.

## Разработка

- **npm test** — сборка HTML, проверки логики, API, хранения и сценариев интерфейса; без сети.
- **npm run test:http** — отдельная проверка локального HTTP-сервера. Требует разрешённых соединений с localhost.
- **npm run build** — пересобрать самостоятельный HTML, список скриптов index.html и sw.js.
- **npm start** — запуск сервера.

Список клиентских файлов, ресурсов и версия находятся в project.config.mjs. Сборка автоматически меняет имя кеша при изменении исходников. Не редактируйте сгенерированные Mii_Ratsion.html и sw.js вручную. Структура и порядок загрузки описаны в ARCHITECTURE.md, результаты проверок — в QA.md.
