# Проверка версии 2.2

14 ноября 2026 года.

35 проверок логики прошли: 8 931 полных локальных продуктов; расчёты и миграция; переводы; дополнительные нутриенты; валидация фото; неполные карточки OFF; реальные нули и отсутствующие значения; канонизация GTIN; запрет сохранения незаполненных КБЖУ в дневнике; самостоятельный HTML с 11 встроенными скриптами и фото воды.

3 проверки прямого API прошли: HTTP 404 означает отсутствие продукта, эквивалентный код с ведущим нулём проверяется после 404, HTTP 503 остаётся ошибкой сервиса. Реальный серверный запрос отсутствующего кода 99999999999999 вернул HTTP 200 и food:null.

43 сценария DOM прошли: сохранение записей и настроек; поиск и отмена устаревших запросов; фото Milka; пересчёт кругов и дополнительных нутриентов при изменении граммов; отсутствие двойного учёта редактируемой записи; загрузка подробностей; незаполненная карточка воды; явное подтверждение нулей; ручное создание отсутствующего продукта по коду; повторный поиск сохранённого штрихкода без сети после перезагрузки; дополнительные круги под БЖУ.

Реальный серверный запрос /api/barcode?code=4820051240233 вернул HTTP 200: название «Вода мінеральна негазована», бренд «Карпатська Джерельна», исходное фото и null для четырёх отсутствующих КБЖУ. Карточка больше не исчезает при разборе ответа. Это проверка конкретного кода, а не всех вариантов воды.

В браузере проверены дневник, каталог и карточка банана при ширине 390 px: поля граммов, даты и выбора приёма пищи имеют вычисленный размер шрифта 16 px; горизонтального переполнения страницы и модального окна нет. Сахара, соль, насыщенные жиры, клетчатка и кальций находятся вместе под БЖУ. У источника есть реальная фотография. Проверка выполнялась в настольном браузере с мобильной шириной; реальное поведение экранной клавиатуры Safari, физическая камера телефона и установка PWA этой версией не проверялись.

Исходные данные могут быть неполными или меняться. Приложение не подставляет отсутствующие нутриенты нулями. Наличие ссылки на фото не гарантирует доступность исходного файла. На GitHub Pages нет Node API: часть функций внешнего каталога требует отдельного сервера, как указано в README.
