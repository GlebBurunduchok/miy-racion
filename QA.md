# Проверка версии 2.3.0

15 ноября 2026 года.

## Автоматические проверки

- 38 проверок логики: профиль, расчёты, 8 931 полная карточка, переводы, импорт, миграция, нутриенты, фото, неполные записи, GTIN и мобильные правила.
- 3 проверки прямого API: отсутствие по HTTP 404, эквивалентный код с ведущим нулём, отличия HTTP 503 от отсутствующего продукта.
- 4 проверки хранения: запрет доступа, квота, копия повреждённого оригинала, защита сохранённого дневника от невалидного состояния.
- 48 сценариев DOM: поиск и устаревшие ответы, языки, фотографии, дневник, порции, редактирование, отмена удаления, вес, избранное, миграция, штрихкоды, повторный поиск без сети, дополнительные нутриенты, редактирование дня из 500 записей, неверный вес и сбои записи.
- HTTP-проверки: все 24 публичных файла, версия сервиса, MIME-защита, валидация аргументов API, методы, закрытые исходные документы, переходы по Windows-путям и 404 для отсутствующих ресурсов.

Основной набор запускается через npm test. Проверка HTTP вынесена в npm run test:http, поскольку ограниченная среда командной строки запрещала TCP-соединения. Тот же HTTP-набор выполнен отдельно в среде с доступом к localhost и прошёл.

## Браузер

Дневник и каталог проверены при ширине 320 и 390 px. На 320 px исправлено переполнение строки даты; ширина содержимого после исправления совпадает с доступной шириной страницы. Поле даты имеет вычисленный размер шрифта 16 px. Круги укладываются в карточки.

Отступ iPhone проверен отдельным макетом с верхней безопасной областью 59 px: логотип и кнопки располагались ниже неё. Это моделирование в настольном браузере, не проверка на физическом iPhone.

Фотография «Куряче філе смажене» из расширенных метаданных действительно загрузилась с сайта источника и отобразилась в поиске и карточке. При онлайн-поиске также загрузились фотографии дополнительных найденных блюд. У 966 из 1 000 встроенных карточек источника есть исходная ссылка на изображение; остальные 34 её не предоставили.

Внешний вид карточки, логотип, дополнительная группа нутриентов и узкий экран проверены визуально. Автоматическая камера, клавиатура Safari и установка на физическом телефоне этой версией не проверялись.

## Практические ограничения

Фотографии по внешним ссылкам требуют доступного источника и могут меняться. GitHub Pages не запускает Node API; это ограничение описано в README. Дневник хранится в браузере и требует резервной копии при переходе на другой адрес или устройство. Проверки не заменяют испытания на реальном телефоне.
