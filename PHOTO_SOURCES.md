# Фотографии продуктов

Встроенная фотография Milka Oreo (EAN 7622210834751):

- Авторы: участники Open Food Facts.
- [Страница продукта](https://world.openfoodfacts.org/product/7622210834751).
- [Исходная выбранная фотография](https://images.openfoodfacts.org/images/products/762/221/083/4751/front_en.42.400.jpg).
- Лицензия: Creative Commons Attribution ShareAlike, согласно [условиям изображений Open Food Facts](https://openfoodfacts.github.io/documentation/docs/Product-Opener/api/tutorials/license-be-on-the-legal-side/).
- Изображение включено без изменения; интерфейс вписывает его в рамку с сохранением пропорций.

Остальные фотографии продуктов загружаются по адресам источников, указанным в данных карточек. Изображения «Таблиці Калорійності» включены как ссылки на исходный сайт; копии этих файлов в архив не помещены. Наличие ссылки не означает, что для каждого продукта есть фотография. Если источник не прислал фото или файл не загрузился, показывается значок.

При открытии карточки приложение может запросить её подробные данные и фото. Такие запросы содержат только код/адрес продукта. Профиль, дневник и личные цели в эти запросы не включаются.
